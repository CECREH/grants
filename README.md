# CECREH funding opportunities

A compact public reference for 22 selected funding programs, with sponsor summaries, funding and match information, submission dates, eligibility notes and official links.

The original 14 programs retain their **October 19, 2026** opening checks and **October 11, 2026** funding snapshot. Eight additions have explicit **October 20, 2026** opening, funding and eligibility checks. Each new route states conditions the applicant must establish. This is a dated reference; confirm current requirements with the sponsor.

The additions are HUD Research Partnerships, EDA Disaster Readiness, Minnesota Life Course Center Emerging Scholars, Charles Pankow Research Need Statements, HUD FHIP General Component, Moody Foundation general/regional inquiry, NBER Health and Aging Emerging Scholar Pilot Proposals, and the Albert and Margaret Alkek Foundation. Moody retains its existing O72 ID; new programs use O91–O97.

NBER requires unverified NIH New or Early-Stage Investigator eligibility; its $30,000–$50,000 is anticipated total direct costs for two years. Alkek is a conditional rolling postal inquiry, requiring TTU Advancement clearance and verification of the applicant entity’s public-charity status and application history. Neither entry confirms applicant eligibility.

Search by sponsor, program, topic or record ID. Filter dated deadlines and rolling routes, then expand a card for eligibility and sources. There are 12 dated and 11 rolling routes; HUD Research Partnerships appears in both because it accepts rolling proposals until a closing date or fund exhaustion. The display contains no internal application priorities, project assignments or preparation dates.

To preview locally, run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory and open `http://127.0.0.1:8765/`. No installation or build step is needed.

The relative asset paths support GitHub Pages project subpaths. `index.html`, `app.js`, `filters.mjs`, `styles.css`, `favicon.svg` and `data/opportunities.json` form the website; `.nojekyll` selects plain static serving from the repository root.

This dashboard implements no sign-in, visitor database, cookies, browser storage or third-party analytics. GitHub performs its own hosting/security logging; see [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
